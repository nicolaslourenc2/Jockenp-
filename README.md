# Jockenpô
Implementação do jogo jokenpô em python

#Descrição
Este é um projeto do jogo Pedra Papel Tesoura em python (Jockenpo). Ele possui 3 modalidades diferentes e é executado totalmente via terminal do python.

#Regras e modalidades
O jogo segue as regras normais do jockenpo (Pedra ganha de Tesoura, Tesoura ganha de Papel, Papel ganha de Pedra)

Ele é divido em 3 modalidades, dentre elas:
Humano x Humano: Duas pessoas jogam entre si no mesmo computador
Humano x Computador: Uma pessoa joga contra o computador que recebe seus valores aleatóriamente
Computador x Computador: Uma partida entre os computadores, decidida com valores aleatórios, a pessoa só comanda se deseja continuar jogando ou não

#Como jogar 
Baixe o arquivo .py e execute na sua IDE

Siga as instruções no terminal

#Tecnologias Utilizadas
Python 3: Linguagem de programação usada para toda lógica do jogo.
